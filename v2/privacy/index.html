隐私政策

更新及生效日期：2026 年 11 月 17 日

阅读是私人的日常。这里说明读迹会保存什么、数据放在哪里，以及你能如何管理它。

  2. 本机存储、小组件与 iCloud 同步
  3. 导出、恢复与删除
  4. 权限与应用锁
  5. 广告、统计与支持邮件
  6. 本网站与政策更新

01 · 记录哪些信息

你主动填写的书名、作者、总页数、书色、阅读状态和完成日期，以及阅读记录的日期、起止页码、时长、阅读时段（清晨、上午、午后、晚间、睡前）和可选笔记，会保存在书库中。笔记可包含格式文字、收藏标记、摘录出处、网页链接，以及你主动添加的图片、扫描文稿和文件附件。应用也会保存主题色、图标、外观、提醒和同步等偏好设置。无需注册读迹账号。

02 · 本机存储、桌面小组件与可选 iCloud 同步

书库默认保存在本机。为了向系统桌面小组件（「继续阅读」「今日光谱」「阅读色带」）提供展示数据，应用会在本机 App Group 容器中写入轻量级摘要快照，仅包含书名、作者、阅读进度、每日页数与时长汇总，不包含你的笔记正文、摘录、图片或文件附件。

你可以主动在应用设置中开启 iCloud 同步，通过 Apple CloudKit 将书库存入你自己的 iCloud 私有数据库，并在使用同一 Apple 账户的设备间同步。Apple 提供并处理这项服务；开发者不通过自有服务器接收你的书库。关闭应用内同步会保留本机书库，不等于删除 iCloud 数据。

03 · 导出、恢复与删除

完整书库备份采用 .dujibackup 备份包，包含书籍、阅读记录、格式笔记及其图片 / 文件附件，以及标识、状态等信息；仍支持导入旧 JSON 备份。恢复时按标识合并：相同标识的数据会被备份覆盖，其他现有数据保留。Excel 导入导出用于交换阅读记录，不是完整书库备份。

导出的文件由你选择保存位置。删除应用内数据不会删除已导出的外部文件。卸载应用通常会移除本机应用数据，但不会自动清除 iCloud 中的书库或外部备份。

04 · 权限与应用锁

睡前提醒使用系统本地通知，在设备上调度，不需要开发者推送服务器。导入和导出仅访问你通过系统文件选择器选定的文件或位置。拍书页和扫描文稿在使用时请求相机权限；通过系统照片选择器仅接收你主动选中的照片。拍书页取词完全在设备上进行文字识别，不将书页或识别文字上传给第三方识别服务。

可选应用锁使用系统设备认证（Face ID、触控 ID 或设备密码），开发者和应用无法读取你的生物识别数据。

05 · 广告、统计与支持邮件

读迹不接入广告或第三方用户行为追踪 SDK，也不通过自有服务器收集你的阅读习惯。Apple 可能根据你的系统设置和其政策处理 App Store、TestFlight 或诊断信息。

如果你主动发送支持邮件，我们会收到你的邮箱地址、邮件内容和附件，仅用于排查问题和回复咨询。请勿发送密码或不必要的敏感信息。

06 · 本网站与政策更新

本网站由 GitHub Pages 托管，不使用分析脚本、广告或追踪 Cookie。GitHub 可能因服务与安全目的记录访问者技术信息，详见 GitHub 隐私声明。Apple 服务信息处理方式请参阅 Apple 隐私政策。
