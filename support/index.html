使用支持

从第一笔记录，到把整个书库带走。常见问题，在这里慢慢找答案。

如何添加书籍和阅读记录？

在「今日」或「所有书籍」中点击添加书籍，填写书名；作者和总页数可以留空。点击右上角对号保存，左上角 × 取消。记阅读时，点击右下角悬浮的「记一笔」按钮，选择书籍并填写起止页码。时长、时段与随手记均为可选。

页数如何计算？能补记或修改吗？

阅读页数按结束页减去开始页计算，例如从第 20 页读到第 40 页记为 20 页。可以在阅读日历中选择日期补记，打开已有记录查看详情，通过记录菜单编辑或删除。请确认日期和页码后保存。

如何找到书籍或标记读完？

「所有书籍」可以按阅读状态查看，并按书名或作者搜索。在书籍详情里编辑书籍信息、查看历史记录，或标记读完并选择完成日期。之后可以恢复为在读；目前不会为重读单独建立一轮记录。

怎样做完整备份？恢复会覆盖什么？

在「更多」中使用书库备份功能，将 JSON 文件保存到你选择的位置。它保留书籍（包括尚未开始阅读的书）、阅读记录、标识、颜色与状态等信息。恢复前会显示预览；确认后按标识合并，相同标识的内容由备份覆盖，其他现有内容保留。建议恢复前先导出当前书库，并自行保管备份文件。

Excel 导出能当完整备份吗？

不能。Excel 用于阅读记录的交换与整理，不完整保留书库结构、未读书籍和全部元数据。长期备份或迁移请使用完整 JSON 书库备份。导入前查看预览，重复导入也应检查记录是否重复。

iCloud 没有立即同步，怎么办？

确认各设备使用同一 Apple 账户、系统允许页间使用 iCloud，并在页间设置中主动开启同步。网络和系统调度可能导致延迟，可以稍后重新打开应用查看。iCloud 同步不能代替独立备份；删除也可能同步到其他设备。不要为排查同步问题直接卸载应用，以免丢失仅保存在本机的记录。

提醒为什么没有出现？

检查系统通知权限、专注模式和应用内提醒时间。提醒使用本地通知，已经记录阅读的日期会跳过提醒。应用会安排未来一段时间（最多 14 天）的提醒，重新打开应用后更新安排。

Face ID 开启后，多任务页面会隐藏吗？

不会。应用锁在打开或返回应用时使用系统认证，多任务页面仍显示内容。认证不可用时可按系统提示使用设备密码。开发者无法绕过设备认证；遇到问题请检查系统 Face ID 与密码设置，必要时联系支持，先不要卸载应用。

删除本机数据，会一并删除云端和备份吗？

本机、iCloud 和导出的文件需要分别确认。开启同步时，应用内的删除可能传播到其他设备；关闭同步并不自动清空云端。清除云端书库前先在所有设备关闭同步，按照应用提示操作。保存在文件应用或云盘中的导出文件需要你自行删除。
