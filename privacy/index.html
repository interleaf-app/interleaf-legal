隐私政策

更新及生效日期：2026 年 11 月 9 日

阅读是私人的日常。这里说明页间会保存什么、数据放在哪里，以及你能如何管理它。

  2. 本机存储与可选 iCloud 同步
  3. 导出、恢复与删除
  4. 权限与应用锁
  5. 广告、统计与支持邮件
  6. 本网站与政策更新

01 · 记录哪些信息

你主动填写的书名、作者、总页数、书脊颜色、阅读状态和完成日期，以及阅读记录的日期、起止页码、时长、时段和可选随手记，会保存在书库中。应用也会保存外观、提醒和同步等设置。无需注册页间账号。

02 · 本机存储与可选 iCloud 同步

书库默认保存在本机。你可以主动在应用设置中开启 iCloud 同步，通过 Apple CloudKit 将书库存入你自己的 iCloud 私有数据库，并在使用同一 Apple 账户的设备间同步。Apple 提供并处理这项服务；开发者不通过自有服务器接收你的书库。同步取决于网络、账户和系统调度，并非实时备份。

关闭应用内同步会保留本机书库，不等于删除 iCloud 数据。开启同步时，删除操作可能传播到其他设备。清除云端书库前，应先在所有设备关闭同步，并按照应用内提示操作。系统的设备备份或 iCloud 备份也可能依照你的系统设置包含本机应用数据，这与应用内同步开关不同。

03 · 导出、恢复与删除

完整书库备份采用 JSON 格式，包含书籍、阅读记录及其标识、状态等信息。恢复时按标识合并：相同标识的数据会被备份覆盖，其他现有数据保留。Excel 导入导出用于交换阅读记录，不是完整书库备份。

导出的文件由你选择保存位置；如果保存到云盘或发送给他人，相应服务或接收方将能够按其规则处理文件。删除应用内数据不会删除已导出的文件。卸载应用通常会移除本机应用数据，但不会自动清除 iCloud 中的书库或外部备份。你可以在应用中查看、编辑、导出或删除记录；没有可用备份或同步副本的数据，开发者无法代为恢复。

04 · 权限与应用锁

提醒功能需要你主动允许本地通知；你可以随时在应用或系统设置中关闭。通知由设备安排，不需要开发者推送服务器。导入和导出仅访问你通过系统文件选择器选定的文件或位置，核心阅读记录功能无需通讯录、位置、相机或照片权限。

可选应用锁使用系统设备认证（例如 Face ID 或设备密码），开发者和应用无法读取你的面容等生物识别数据。开启应用锁后，多任务切换器仍会显示页面预览；应用锁用于打开或返回应用时认证，不会遮盖多任务预览。

05 · 广告、统计与支持邮件

页间不接入广告或第三方用户行为追踪 SDK，也不通过自有服务器收集你的阅读习惯。Apple 可能根据你的系统设置和其政策处理 App Store、TestFlight、使用情况或诊断信息，并可能向开发者提供相应报告。

如果你主动发送支持邮件，我们会收到你的邮箱地址、邮件内容和你选择的附件，仅用于处理咨询和排查问题。请避免发送密码、完整书库或不必要的敏感信息。邮件服务提供商（例如 Microsoft Outlook）也会按其政策处理邮件。有关支持邮件的访问、更正或删除请求，可通过下方邮箱联系。

06 · 本网站与政策更新

本网站由 GitHub Pages 托管，不使用分析脚本、广告或追踪 Cookie；字体与图片随站点提供。GitHub 可能为提供服务、安全和日志等目的处理访问者 IP 等技术信息，详见 GitHub 隐私声明。Apple 服务的信息处理方式可参阅 Apple 隐私政策。

功能或数据处理方式调整时，我们会更新本页及日期，并在需要时请求相应权限。适用范围为页间应用及本支持网站。如有隐私问题，请联系下方邮箱。
